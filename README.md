# 저랑 데이트할래요? 💌 (Asking Date Mobile Web App)

카카오톡으로 공유할 수 있는 모바일 최적화 데이트 신청 인터랙티브 웹앱입니다.

---

## ✨ 주요 기능
1. **1단계 ("저랑 데이트할래요?")**:
   - **좋아요 ❤️**: 누르면 팡파레(컨페티)와 함께 다음 단계로 진행
   - **싫어요 💔 (도망가는 버튼)**: 모바일 터치(`touchstart`/`pointerdown`) 또는 PC 마우스 접근 시 화면 곳곳으로 재빠르게 순간이동하며 유쾌한 멘트를 출력합니다. 도망갈 때마다 '좋아요' 버튼이 점점 커져 결국 '좋아요'를 누를 수밖에 없게 만듭니다.
2. **2단계 ("헉... 사실 거절할 줄 알았는데 좋다니 저도 좋아요 ><")**:
   - 한식, 양식, 일식, 중식, 아시안/분식, 카페/디저트 등 음식 카테고리 다중 선택 (복수 선택 가능)
   - 못 먹는 음식 / 가고 싶은 맛집 메모 입력 (선택)
   - 선호하는 요일/시간대 입력 (선택)
3. **3단계 (구글 시트 자동 저장 & 접수 완료)**:
   - 선택 완료 시 **내 구글 스프레드시트에 실시간으로 새 행(Row) 추가**
   - 사용자에게는 접수 완료 화면 및 카카오톡 공유 버튼 제공
4. **카카오톡 공유 최적화**:
   - 모바일 인앱 브라우저 완벽 대응
   - 카톡 채팅방에 링크 전송 시 예쁜 썸네일과 안내 문구가 뜨도록 Open Graph 메타태그 설정

---

## 🚀 1. 로컬에서 바로 실행해보기

터미널에서 아래 명령어로 로컬 서버를 띄울 수 있습니다:

```bash
# 프로젝트 폴더로 이동 후
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 에 접속하면 바로 작동 화면을 테스트할 수 있습니다.  
(크롬 개발자 도구의 **모바일 보기 모드(F12 -> 디바이스 툴바)**로 보시면 스마트폰과 동일하게 터치 회피 효과를 확인할 수 있습니다.)

## 📊 2. 구글 스프레드시트 연동 (2분 완성)

별도의 백엔드 서버나 유료 서비스 없이 **무료 Google Apps Script**로 연동됩니다:

1. [Google 스프레드시트](https://sheets.new)에 접속하여 새 시트를 만듭니다. (시트 이름 예: `데이트 신청 결과`)
2. 상단 메뉴에서 **[확장 프로그램] -> [Apps Script]**를 클릭합니다.
3. 열린 편집기 창의 기존 코드를 지우고, 이 프로젝트의 **`google-apps-script.js` 파일 내용**을 그대로 복사하여 붙여넣습니다.
4. 오른쪽 상단 파란색 **[배포]** 버튼 클릭 -> **[새 배포]** 선택.
5. 설정(톱니바퀴 아이콘)에서 **[웹 앱]**을 선택하고 아래와 같이 설정합니다:
   - **설명**: `데이트 답변 수집용`
   - **다음 사용자로 실행**: `나 (내 구글 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`** ★반드시 선택!
6. **[배포]** 버튼을 누르고 Google 계정 권한 승인을 완료하면 **`웹 앱 URL`**이 발급됩니다.
7. 이 프로젝트의 `app.js` 파일 9번째 줄에 해당 URL을 붙여넣으세요:
   ```javascript
   const GOOGLE_SHEET_WEB_APP_URL = "여기에_발급받은_웹앱_URL_붙여넣기";
   ```

*참고: 구글 시트 URL을 넣기 전에는 자동으로 '데모 모드'로 작동하여 기능 테스트가 가능합니다.*

## 🌐 3. 무료로 웹 링크 배포하기 (상대방에게 보낼 링크 만들기)

제작된 웹앱은 정적 파일(`index.html`, `style.css`, `app.js`)로 구성되어 있어 1분 만에 무료 배포할 수 있습니다.

### 방법 A: Vercel 배포 (가장 추천, 1분 소요)
1. [Vercel](https://vercel.com)에 로그인.
2. GitHub 저장소와 연결하거나 Vercel CLI(`npx vercel`)를 사용하여 즉시 `https://내프로젝트.vercel.app` 링크 생성.

### 방법 B: GitHub Pages 배포
1. GitHub에 현재 프로젝트를 Push합니다.
2. 해당 레포지토리의 **Settings -> Pages** 메뉴로 이동합니다.
3. Branch를 `main` (또는 `master`), 폴더를 `/ (root)`로 설정하고 Save를 누릅니다.
4. 잠시 후 `https://<내아이디>.github.io/<저장소이름>/` 주소로 배포가 완료됩니다.

---

## 💬 4. 카카오톡 공유 시 썸네일/문구 바꾸기
`index.html` 파일의 상단 `<head>` 태그 내 Open Graph 메타태그를 원하는 이미지와 문구로 자유롭게 변경할 수 있습니다:

```html
<meta property="og:title" content="소중한 질문이 도착했습니다 💌">
<meta property="og:description" content="저랑 데이트할래요? 솔직하게 답해주세요! 🥰">
<meta property="og:image" content="원하는_이미지_URL">
```
